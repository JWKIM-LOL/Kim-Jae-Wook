# 🐍 Python PBL

## 📂 Список проектов

### 📝 PBL 01. Учёт оценок студентов на основе ООП
Файл: `PBL01_student_scores.py`

Класс читает оценки студентов из текстового файла, считает средний балл, находит студентов с баллом не ниже среднего и сохраняет данные студентов с баллом ниже среднего в отдельный файл.

Использованные библиотеки: `os`, `textwrap`

---

### 🌐 PBL 02. Анализ обращений по IP-адресам в файле журнала
Файл: `PBL02_ip_log_analysis.py`

Скрипт находит все IP-адреса в файле журнала, считает частоту каждого адреса, выводит три самых частых адреса и сохраняет результат в файл CSV.

Использованные библиотеки: `os`, `re`, `csv`, `collections.Counter`

---

### 🛡️ PBL 03. Наблюдение за папкой ради поиска угроз безопасности
Файл: `PBL03_directory_monitor.py`

Скрипт следит за папкой, находит новые файлы, отмечает файлы с подозрительным расширением и ищет в их содержимом комментарии, почтовые адреса и запросы SQL с помощью регулярных выражений.

Использованные библиотеки: `os`, `re`, `time`, `sys`

---

### 📈 PBL 04. Разбор продаж по месяцам
Файл: `PBL04_sales_analysis.py`

Класс создаёт случайные данные о ежедневных продажах за 2024 год, считает сумму продаж по месяцам и строит линейный график с отметками максимума, минимума и среднего значения.

Использованные библиотеки: `numpy`, `pandas`, `matplotlib`

---

### 🎓 PBL 05. Наглядный разбор успеваемости студентов по предметам
Файл: `PBL05_student_score_analysis.py`

Класс создаёт случайные оценки двадцати студентов по трём предметам и строит два столбиковых графика, один со средним баллом по каждому предмету, другой с пятью студентами, у которых самый высокий средний балл.

Использованные библиотеки: `numpy`, `pandas`, `matplotlib`

---

### 💰 PBL 06. Разбор выручки и вклада клиентов
Файл: `PBL06_customer_sales_analysis.py`

Класс обрабатывает данные о покупках клиентов, считает выручку по месяцам и строит столбиковый график с общей выручкой, а также круговую диаграмму с долями выручки по каждому клиенту.

Использованные библиотеки: `pandas`, `matplotlib`
